# Наследие Таджикистана — GitHub Pages

Многостраничный статический сайт на HTML, CSS и JavaScript. Python и Flask не нужны.

## Публикация
1. Создай репозиторий GitHub, например `nasledie-tajikistan`.
2. Загрузи **содержимое этой папки** в корень репозитория.
3. Открой `Settings` → `Pages`.
4. Выбери `Deploy from a branch`, ветку `main`, папку `/ (root)`, нажми `Save`.
5. Дождись появления ссылки GitHub Pages.

## Общие комментарии
GitHub Pages не умеет сам хранить сообщения: это статический хостинг. Чтобы комментарии видели все, подключи бесплатный Supabase.

1. Создай проект на https://supabase.com/.
2. В `SQL Editor` выполни:

```sql
create table public.comments (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) between 1 and 40),
  city text not null check (char_length(city) between 1 and 60),
  message text not null check (char_length(message) between 2 and 600),
  created_at timestamptz not null default now()
);
alter table public.comments enable row level security;
create policy "Public can read comments" on public.comments
for select to anon using (true);
create policy "Public can add comments" on public.comments
for insert to anon with check (
  char_length(trim(name)) between 1 and 40 and
  char_length(trim(city)) between 1 and 60 and
  char_length(trim(message)) between 2 and 600
);
```

3. В настройках проекта Supabase скопируй Project URL и публичный anon/publishable key.
4. Вставь их в `supabase-config.js`.
5. Сохрани и отправь изменения в GitHub.

**Не вставляй service_role/secret key в сайт.** Публичная гостевая книга может получать спам; перед широкой публикацией добавь CAPTCHA, лимиты и модерацию.

## Страницы
`index.html`, `history.html`, `peoples.html`, `culture.html`, `guestbook.html`.

Можно проверить локально через `python -m http.server 8000`, затем открыть `http://localhost:8000`.
